# Photo Commander

Двухпанельный файловый менеджер в стиле Norton Commander (WPF, .NET 8) для разбора фотографий:
поиск одинаковых и похожих фото через OpenCV и раскладка по папкам с датами.

```
┌──────── левая панель ────────┬──── команды ────┬──────── правая панель ───────┐
│ ..                           │ F5 Копировать → │ ..                           │
│ [2024]                       │ F6 Переместить →│ [Архив]                      │
│ IMG_0001.jpg   3,2 МБ        │ Поиск похожих   │                              │
│ IMG_0002.jpg   3,1 МБ        │ Сортировка      │                              │
│                              │ Просмотр        │                              │
└──────────────────────────────┴─────────────────┴──────────────────────────────┘
```

## Запуск

1. Установите .NET 8 SDK (один раз):
   ```
   winget install Microsoft.DotNet.SDK.8
   ```
   После этого **закройте и заново откройте** командную строку.
2. Дважды щёлкните `run.bat`. Первый запуск дольше: скачиваются пакеты OpenCV.

Если нужен отдельный `PhotoCommander.exe`, который работает без установленного .NET, запустите `publish.bat`.
Готовый файл появится в папке `publish`.

Проект открывается и в Visual Studio 2022: `PhotoCommander.csproj` → F5.

## Как пользоваться

* **Активная панель** (с яркой рамкой) — это источник. Другая панель — куда копировать, перемещать или сортировать.
* `Tab` — переключить панель, `Enter` — открыть, `Backspace` — вверх, `Ctrl`/`Shift` + клик — выделить несколько.
* `F5` копия, `F6` перенос, `F7` новая папка, `F8`/`Del` — в Корзину (файлы можно восстановить), `Ctrl+R` — обновить.

### Поиск похожих
Ищет фото в папке активной панели:
1. **точные копии** — по MD5;
2. **похожие** (другой размер, сжатие, формат) — по перцептивному хэшу (DCT из OpenCV) с порогом «Порог сходства»;
3. **снятые подряд** — фото, снятые в пределах N секунд (по EXIF), сравниваются с более мягким порогом.
   Так находятся серии кадров.

В окне результатов по умолчанию отмечено всё, кроме лучшей копии (наибольшее разрешение, затем больший размер файла).
Отмеченные файлы можно переместить (по умолчанию в `_duplicates` с сохранением подпапок) или отправить в Корзину.

### Сортировка по датам
Раскладывает фото из активной панели в папки вида `2024\2024-07` внутри папки другой панели.
Можно копировать или перемещать и пропускать дубликаты.

## Python-версия
`python/photo_dedup.py` — тот же алгоритм для командной строки:
```
py -m pip install opencv-python numpy pillow
py python\photo_dedup.py "C:\Фото" --move-dups
```
